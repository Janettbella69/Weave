连接你的 Agent

当前是本机单人原型。密钥在项目的 .env 文件配置。

  1. 复制 .env.example 为 .env。
  2. 填写 ANTHROPIC_API_KEY 和 ANTHROPIC_MODEL，启用真实模型协商。
  3. 填写 NOTION_TOKEN 和 NOTION_PAGE_ID，并授权该页面给 integration。
  4. 重启服务，在聊天中的计划卡片确认、同步。

当前聊天入口使用规则识别状态和反馈；配置模型后，团队协商使用真实模型。跨用户 Agent 协作暂未接入此聊天版。
