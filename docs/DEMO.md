# Weave · 黑客松演示脚本

开场：**每个人都有一个懂自己的 Agent。Weave 让它们对内协调生活，对外协商一起行动。**

## 0:00–0:45 我的习惯 Agent 团队

Lulu 说：“昨晚睡了 5 小时，今天想练腿，晚上还要聚餐。”

展示运动、睡眠、饮食三个 Agent 的建议与协调结果。解释计划为什么调整，确认后可以写进 Notion。现场若未配置模型，明确这是规则演示。

## 0:45–2:00 我的 Agent 遇见你的 Agent

Lulu 邀请阿梦散步，明确授权本次时间共享。切换阿梦视角，授权。

展开记录：周三 20:00 提案被拒绝 → 周五 18:30 反提案被拒绝 → 周三 18:30 被双方 Agent 接受。

展示这是各自可用时间驱动的决策，不是一段预先写好的聊天：修改阿梦的时间可以得到不同方案或没有共同时间。个人习惯反馈不会出现在协商记录中。

## 2:00–2:30 双方确认，再一起行动

阿梦先确认，日程仍为空。Lulu 再确认，双方各自出现活动。导出 .ics，或在有真实配置的情况下同步各自 Notion。

说明：两个 Agent 达成一致不等于用户已同意；Weave 保留最终确认权。

## 2:30–3:00 从一次行动到长期习惯

设置一个短期提醒并展示到期后进入聊天。记录“午饭后散步更容易坚持”，下一次个人计划参考反馈。

结束：**从我的 Agent 帮我坚持，到我们的 Agent 帮我们一起做到。**

## 必须如实区分

- 此版是本机双角色演示；人物切换不是身份认证。
- A2A 使用本地自定义规则协议。内部习惯协商可选真实模型。
- 微信（agent-wechat）和 Notion 是已实现的连接器，真实在线状态取决于外部服务和配置。微信不是官方接口。
- 日程写入的是 Weave 本地日程，.ics 由用户导入；不声称已写入系统日历。
