# Weave 网页 v3 · 第一块 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the web workspace with the v3 design (chat home, 待办, 目标, 记录, 设置, 助理主页, 第一次打开) and add the small backend it needs: a goals layer, web check-in, a one-off `set_reminder` tool, richer `/api/status`, Beijing time by default.

**Architecture:** Backend changes stay in the existing modules (`habits.mjs` owns goals and check-in rules, `api.mjs` exposes them, `agent-tools.mjs` + `hosted/agent-service/mcp/tools.mjs` expose tools, both snapshot files carry the new tables). The frontend keeps `Workspace.jsx` as a thin shell (data loading, routing, navigation) and moves each page into its own component; every computation a page shows (to-do rows, goal cards, month calendar, date labels, chat separators) lives in a tested pure `.mjs` module. All user-facing strings live in `copy.mjs` (plus the WeChat strings that already live in `wechat-row.mjs`).

**Tech Stack:** Next.js 16 app router via vinext on Cloudflare `wrangler dev`, React 19 client components in `.jsx`, plain CSS in `hosted/app/globals.css`, `lucide-react` icons (already a dependency), Node `node:test` for root tests, zod for agent-service tool shapes.

**Spec:** `docs/superpowers/specs/2026-11-03-frontend-v3-design.md`. Visual reference: the v3 page of https://claude.ai/artifact/QvWed1pz3SuPRTdFFMZjmj (10 boards; colours and spacing below are copied from it).
