## 1. 要做成什么

把网页换成设计稿 v3：**聊天（首页）/ 待办 / 目标 / 记录 / 设置 / 助理主页 / 第一次打开**。电脑上用左侧导航，手机上用底部五个标签（聊天、待办、目标、记录、设置）。让「最重要的功能」上线：定目标 → 每天在待办里打勾 → 在目标和记录里看到进展。后端只补最少的东西；Weave 主动醒来那一套放第二块。

成功标准（上线前逐条验）：

1. 页面和设计稿 v3 一致（配色、结构、文字）。
2. 待办里打勾，记录页当天变成「做到了」，来源写「你在网页上记的」；取消勾，当天那条删掉。
3. 在聊天里跟 Weave 定一个目标，目标页「正在追踪」里出现这个目标和它下面的小习惯。
4. 在聊天里说「明天 8 点提醒我给妈妈打电话」，助理主页的「只响一次」和待办的「之后」里出现这条。
5. 电脑（1280 宽）和手机（390 宽）都能用。
6. 界面上没有英文小标题、工程参数、点了没反应的按钮、「反馈：」暗号；没开通的功能照实写没开通。
7. 根目录 `npm test`、agent-service 测试和 CI（PR → `feat/deploy-tencent`，含容器测试和部署冒烟）全部通过。

## 2. 她已经定下的前提（直接用，不再问）

- 参考 Muse 的样子和结构：Goal 和 Tracking 在同一页；提醒按「只响一次 / 每天 / 每周 / 每月」分组。
- Weave 是 personal Agent + 长期记忆 + 主动找你；聊天是首页。
- 「今天」改为「待办」。
- 时区默认北京时间（她的大部分用户在中国），不自动改成浏览器时区，设置里能改。
- 之前的方案保留：Notion 一键连接、设置里微信一行（没配置时「即将开通」）。
- 用户侧一律傻瓜式：界面不出现 ID、密钥、回调地址。

## 3. 页面

每一页写三件事：显示什么、数据从哪来、特殊状态。

### 3.1 聊天（首页）

- 整页对话：日期分隔（昨天 / 今天）、Weave 浅灰气泡、你的浅蓝气泡、胶囊输入框、浅蓝圆形发送键，底部一行「聊天内容会发给 DeepSeek 生成回复。」。
- 数据：`GET /api/status` 的 `messages`；发送走现有 `POST /api/chat`。发送中的显示、输入法回车不发送、markdown 渲染，沿用现有已测模块（`chat-pending.mjs`、`chat-input.mjs`、`markdown.mjs`）。
- 顶部 Weave 头像和「已连接」，点一下进入助理主页。
- 主动消息标记（时钟图标 +「HH:MM · Weave 主动来问」）：只在消息带「主动发出」标记时显示。第一块不新造这类消息，只把显示做好；有了第二块之后自然出现。
- 快捷回复按钮（做到了 / 今天下雨了 / 晚点再问我）属于第二块，第一块不显示。

### 3.2 待办

- 顶部：日期 +「今天 n / m」。
- 「今天」：每个在追踪的习惯一行。勾选框（44px 点击区）、习惯名、「为了「目标名」 · 什么时候 · 最小一步」。没打勾且昨天没做时，挂一句「连着错过」提示（设计稿原句只适合走路，改成通用说法，见附录 A-4）；打勾后挂「记下了，这周第 N 天。」。
- 「之后」：还没到点的「只响一次」提醒（来自 `reminders`）。打勾 = 取消这条提醒（走现有 `POST /api/reminders/cancel`）。没有就不显示这一栏。
- 底部：「想加别的事？在聊天里跟 Weave 说一声。」
- 数据：`status.habits`、`status.completions`、`status.reminders`、`status.today`。
- 打勾先变勾（乐观更新），失败退回并提示。只能勾今天；补记以前的日子在聊天里跟 Weave 说。

### 3.3 目标

- 「正在追踪」：每个目标一张卡。类别图标、目标名、「类别 · 从 X 月 X 日开始」、「这周 n 天」、每个小习惯一行（名字 + 最近 7 天圆点）、「最近：日期，来源「备注」」。
- 没挂目标的旧习惯，归到一张「还没归到目标的习惯」卡里（【待确认】）。
- 「创建一个目标」：健康 / 人际关系 / 财务 / 事业 / 兴趣爱好 / 效率 / 其他。点一类，在本页出一个小对话框：第一句是固定引导语「好，聊聊「类别」。你想做到什么？说说现在的情况就行，我帮你拆成每天的一小步。」；你发的话照常进同一个聊天（带上类别，让 Weave 知道语境），Weave 追问、提建议，你同意后它用 `save_goal` + `save_habit` 存好。
- 数据：`status.goals`、`status.habits`、`status.completions`。

### 3.4 记录

- 顶部按习惯切换（胶囊按钮）；当月日历（做到了 / 没做 / 还没开始）、三个数（本月做到几天、最长一次连续、连着错过两天的次数）、「最近记下的」（日期、来源标签「你在网页上记的」/「Weave 帮你记的」、备注）。
- 月份可以前后翻。
- 数据：`status.completions`（最近 62 天）；更早的月份第一块不翻（翻到头时按钮置灰，【待确认】一句说明）。

### 3.5 设置

- 连接：Notion（沿用 #18 的一键连接和各种回跳状态；服务器没配置 Notion 时整行隐藏）；微信群（沿用 #22：没配置写「即将开通」；配置了走现有绑定流程，改两处，见下）。
- 微信绑定流程的两处改动（来自 11-03 真机绑定的教训）：
  1. 「复制绑定消息」做成主按钮，只复制「绑定 码」这几个字；「在微信中发送：」这类提示不放进可选中的文字里；加一句提示：只有这句原样发过去才算数。（【待确认】）
  2. 再点「连接」会让旧码立刻作废：已经有码时，按钮改成「换一个新码」，旁边写「换新码后，旧码就不能用了」。（【待确认】）
- 时间：「所在地时间」下拉（北京时间 / 洛杉矶时间 / 纽约时间 / 伦敦时间 / 东京时间 / 新加坡时间），存到 `profile.timezone`；一行「Weave 什么时候主动找你 → 去助理主页看」。
- 数据与隐私：说明 + 隐私说明链接、导出我的数据（现有 `/api/export`）、删除账号（现有确认流程）。

### 3.6 助理主页

- 头像、名字 Weave、「已连接」（绿色闪电）。两个栏目：提醒、记忆。
- 提醒栏：
  - 顶部固定一段说明主动提醒还没开通。设计稿原句是「主动提醒还没开通。现在 Weave 只在你打开网页、给它发消息时回复你；开通以后，它会按下面的安排主动来找你。」；加了 `set_reminder` 以后，Weave 会按你交代的时间提醒一次，原句前半句就不准了，改法见附录 A-4（【待确认】）。
  - 「只响一次」：未到点的提醒，每条可删除（现有 `reminders/cancel`）。第一块不做「暂停」。
  - 「每天 / 每周 / 每月」：只有标题和「暂时没有安排。」（设计稿原句）。「多找我一点 / 少找我一点 / 别主动找我」第一块不显示。
- 记忆栏：现有 `GET /api/agent-memory` 返回的原文，只读，按 markdown 显示；顶部一句说明（【待确认】：「这些是 Weave 自己记下的关于你的事。哪条不对，直接在聊天里跟它说。」）；「忘掉」第二块做。

### 3.7 第一次打开

- 条件：没有任何习惯，也没有聊过天。
- 设计稿原样：头像、「你好，我是 Weave」、「先选一件最想养成的小事……」、五个选项、选中后的计划卡。
- 点「就这样开始」：把「我想从「饭后走走」开始，第一步：吃完饭，穿上鞋走到楼下。」这样一句话发给 Weave（【待确认】），然后切到聊天页。Weave 按 3.3 的方式确认并保存。

### 3.8 拿掉的东西

旧的提醒表单页（标题「把商量好的事，留给生活。」）、旧记忆页（目标与偏好表单、「反馈：」说明、通知列表）、设置里的「目标与偏好」表单、页脚「由你授权，由你决定。· 时区英文名」、协作和主动页（早已隐藏）。后端接口都留着，只是前端不再调用。

## 4. 后端改动

### 4.1 目标这一层

- `person.goals = [{id: 'g:'+uuid, title, category, createdAt, updatedAt, archived}]`
  - `title` 1–30 字；`category` ∈ `health | relationships | finance | career | interests | productivity | other`；最多 10 个未归档目标。
- 习惯加可选的 `goalId`；旧习惯没有，照常工作。
- 写入函数放在 `hosted/lib/weave/habits.mjs`（和 `saveHabit`、`logCompletion` 一起）。

### 4.2 工具：`save_goal`，`save_habit` 加 `goal_id`，`set_reminder`（只响一次）

- `save_goal`（owner 范围）：新建或修改目标。新建不带 `goal_id`；修改带 `goal_id`，只改给了的字段；`archived: true` 表示不再追踪。
- `save_habit` 增加可选参数 `goal_id`。
- `set_reminder`（owner 范围，只响一次）：参数 `text`（1–500 字）和 `due_at`（ISO 时间，必须在将来），调用现有 `domain.addReminder`。到点后的送达走现有逻辑：网页每次请求时把到点提醒写进聊天和通知；服务器配了微信、桥接在跑时，现有 `scheduler.mjs` 会排进微信。名字和第二块「主动醒来」设计里定的一致，第二块在它上面加每天 / 每周 / 每月。
- 开工前按仓库 AGENTS.md 第二条，先查 Claude Agent SDK 文档里自定义工具的写法（`tool()` 定义、注解），照现有 `save_habit` 的写法加。
- 三个工具说明都是给模型看的文字，【待确认】，原稿见附录 A-1 至 A-3。

**教材依据**

- PDF 第 55 页：「判据:动作可逆、不碰生产数据,就全自动。动作不可逆、碰业务数据,就暂写+确认。」
- PDF 第 56 页「动作三级」：「预览　展示将要做的事,用户不反对就做」；「确认　暂写,人点确认　写入业务数据、对外发消息、高风险决策」。
- 现在的代码：`save_habit`、`log_completion` 直接写入（11-02 定的）。
- 结论：`save_goal`、`set_reminder` 跟 `save_habit` 一样直接写，按「预览」档用：Weave 先在聊天里把要存的目标、每天的小事或提醒说出来，你不反对再存；存了能在聊天里改或撤（归档目标、删提醒），可逆。

**我的看法**：目标和提醒是你自己在 Weave 里的数据，可改可撤，不是对外写入，所以不需要「暂写 + 点确认」卡。写进 Notion 仍按 11-02 定的「暂存 + 确认」（第二块）。

### 4.3 快照（给 Agent 查的 weave.db）

- 加 `goals` 表（`goal_id, title, category, archived, created_at`）；`habits` 表加 `goal_id` 列；加 `reminders` 表（`reminder_id, text, due_at, status`），让 Weave 能查到自己设过的提醒。
- 对应的快照测试跟着更新。

### 4.4 接口

- `GET /api/status` 多返回：`goals`、`habits`、`completions`（最近 62 天）、`today`（按本人时区算的当地日期 `YYYY-MM-DD`）。
- `POST /api/habits/check {habit_id}`：按本人时区算出今天，调 `logCompletion`，来源记 `web`；重复点不重复记。
- `POST /api/habits/uncheck {habit_id}`：删掉今天那一条（不论是谁记的）。
- 只处理今天。补记以前的日子在聊天里说，由 Weave 用 `log_completion` 记。

### 4.5 时区

- 去掉 #17 加的「首次打开时，如果是默认上海时区，就静默改成浏览器时区」。
- 新账号默认 `Asia/Shanghai`（现状不变）。设置里能改，改动走现有 profile 接口。
- 她自己的账号已经被 #17 改成了洛杉矶。这次不悄悄改回去，她在设置里自己选。

### 4.6 不动的

聊天接口、Notion、微信后端（`wechat.mjs` 的接口）、导出、删账号、`proactivity.mjs`、`dispatcher.mjs`、`hosted/agent-service` 里除工具定义和提示词以外的部分。

「在某个时间提醒对方一次，比如「明天晚上 8 点提醒我给妈妈打电话」。due_at 用 ISO 时间，按对方的当地时间换算，必须在将来。先跟对方说清楚什么时候提醒、提醒什么，对方没反对再调用。到点后，提醒会出现在对方的聊天里；对方接了微信的话也会发到微信。」

**A-4 界面上的新句子**
- 待办里「连着错过」提示：「昨天没做，今天做一下就不算连着错过。」（设计稿里写的是「昨天没走，今天走一下……」，那句只适合走路；改成通用说法）
- 待办空的时候：「还没有每天要做的事。去「目标」定一个，或者在聊天里跟 Weave 说说你想养成什么。」
- 目标页没有目标时：「还没有在追踪的目标。从下面选一类开始。」
- 没归到目标的旧习惯那张卡的标题：「还没归到目标的习惯」
- 记录页没有记录时：「还没有记录。在待办里打勾，或者跟 Weave 说一声，这里就会有。」
- 记录页翻到最早一个月时：「更早的记录先看不了。」
- 记忆栏顶部：「这些是 Weave 自己记下的关于你的事。哪条不对，直接在聊天里跟它说。」
- 记忆是空的：「Weave 还没有记下关于你的事。」
- 加载失败：「没加载出来。」+ 按钮「重试」
- 打勾没记上：「没记上，再点一次试试。」
- 第一次打开点「就这样开始」时替你发出的那句：「我想从「{选项}」开始，第一步：{第一步}。」
- 微信绑定：主按钮「复制绑定消息」；提示「把这句原样发给 Weave 的微信，多一个字都不算。」；已有码时按钮「换一个新码」，旁边「换新码后，旧码就不能用了。」
- 助理主页提醒栏顶部（改设计稿原句）：「主动提醒还没开通。现在 Weave 只会在你交代的时间提醒你一次；开通以后，它会按下面的安排主动来找你。」
